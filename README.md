# LapTechMac

Sitio web informativo y de gestión de pedidos para venta de equipos Apple, desarrollado para un cliente real. Los administradores registran los servicios y asignan un ID único a cada cliente, quien puede consultar el estado y precio de su servicio con ese identificador.

🔗 **Live:** https://www.laptechmac.com

## Funcionalidades

- Catálogo informativo de productos y servicios
- Registro de servicios por parte de administradores
- Consulta de estado y precio mediante ID de cliente

## Stack

- Next.js + TypeScript
- SQL

## Desarrollo local

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000) para verlo.
